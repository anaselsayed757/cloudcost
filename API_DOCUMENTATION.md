# CloudCost — REST API Documentation

## Overview

CloudCost provides a RESTful API for managing cloud infrastructure costs, forecasts, budgets, and alerts.
All responses are JSON. Interactive docs are auto-generated by FastAPI.

| Interface | URL |
|---|---|
| Swagger UI | `http://localhost:8000/docs` |
| ReDoc | `http://localhost:8000/redoc` |
| OpenAPI JSON | `http://localhost:8000/openapi.json` |

---

## Authentication

All endpoints (except `/health` and `/auth/login` and `/auth/setup-admin`) require a JWT Bearer token.

```
Authorization: Bearer <token>
```

Tokens are valid for **24 hours**. Obtain one via `POST /auth/login`.

**Error responses:**

| Status | Meaning |
|---|---|
| 401 | Missing or expired token |
| 403 | Valid token but insufficient role (viewer trying admin action) |

---

## Role system

| Role | Permissions |
|---|---|
| `admin` | Full access — can run billing, manage users, tariffs, budgets, clear alerts |
| `viewer` | Read-only — can view all data, acknowledge and resolve alerts |

---

## Status codes

| Code | Meaning |
|---|---|
| 200 | OK |
| 201 | Created |
| 400 | Bad request / validation error |
| 401 | Unauthenticated |
| 403 | Forbidden (wrong role) |
| 404 | Not found |
| 422 | Request body failed Pydantic validation |
| 429 | Rate limit exceeded |
| 500 | Server error |

## Authentication endpoints

### Login
```
POST /auth/login
Content-Type: application/x-www-form-urlencoded
```

Rate-limited to **10 requests per minute** per IP.

**Body (form fields):**
| Field | Type | Description |
|---|---|---|
| `username` | string | Account username |
| `password` | string | Account password |

**Response (200):**
```json
{
  "access_token": "eyJhbGci...",
  "token_type": "bearer",
  "role": "admin",
  "username": "admin"
}
```

**Example:**
```bash
curl -X POST http://localhost:8000/auth/login \
  -d "username=admin&password=cloudcost2024"
```

---

### Bootstrap admin (first run only)
```
POST /auth/setup-admin
```
Creates the default `admin` account. Idempotent — safe to call multiple times; does nothing if admin already exists. No authentication required (bootstrap endpoint).

**Response:**
```json
{ "status": "admin created", "username": "admin" }
```

## Billing endpoints

### Run billing
```
POST /billing/run
```
**Auth:** Admin only.

Calculates costs for all VMs for the current hour using live Prometheus metrics. Also runs automatically every hour via the internal scheduler.

**Response:**

  "billed": 2,

      "total_cost": 0.0052,

      "ram_cost": 0.0013,
      "net_cost": 0.0001

}

### Send billing receipt
```
POST /billing/receipt
```
**Auth:** Admin only.

Sends a billing receipt email with a CSV attachment to a specified recipient.

**Body:**
```json
{
  "client_email": "client@example.com",
  "recipient_email": "billing@example.com",
  "days": 30
}
```

`client_email` must match the `owner_email` stored on the VM records. `recipient_email` defaults to `client_email` if omitted.

**Response:**
```json
{
  "sent": true,
  "client_email": "client@example.com",
  "recipient_email": "billing@example.com",
  "days": 30,
  "vm_count": 2,
  "record_count": 1440,
  "total_cost": 3.4812
}
```

## Forecast endpoints

### Get cost forecast
```
GET /forecast/{instance}
```
**Auth:** Any authenticated user.

Trains both a **Linear Regression** and an **ARIMA(2,1,2)** model on the last 30 days of daily aggregated cost data and returns 30-day predictions from both. The better-performing model (lower RMSE) is marked as recommended.

Requires at least **3 days of billing history**.

**Response:**
```json
{
  "vm_instance": "10.150.40.10:9100",
  "recommended_model": "arima",
  "total_30d_estimate": 1.5240,
  "daily_forecast": [
    { "date": "2026-05-14", "predicted_cost": 0.0502 },
    { "date": "2026-05-15", "predicted_cost": 0.0510 }
  ],
  "validation": {
    "linear_regression": { "rmse": 0.0021, "mape": 4.32 },
    "arima":             { "rmse": 0.0014, "mape": 2.87, "aic": -312.5 }
  },
  "models": {
    "linear_regression": [0.0502, 0.0508, "..."],
    "arima":             [0.0499, 0.0507, "..."]
  }
}
```

**Insufficient data response:**
```json
{
  "vm_instance": "10.150.40.10:9100",
  "error": "Not enough data yet — need at least 3 days of billing history",
  "days_available": 1
}
```

## Alert endpoints

### List alerts
```
GET /alerts/?status=firing
```
**Auth:** Any authenticated user.

**Query parameters:**
| Param | Values | Description |
|---|---|---|
| `status` | `firing` (default), `all` | `firing` returns only unresolved alerts |

---

### Alert summary
```
GET /alerts/summary
```
**Auth:** Any authenticated user.

**Response:**
```json
{ "critical": 1, "warning": 3, "total": 4 }
```

---

### Acknowledge alert
```
POST /alerts/{alert_id}/acknowledge
```
**Auth:** Any authenticated user.

Marks the alert as reviewed. Does not resolve it.

---

### Resolve alert
```
POST /alerts/{alert_id}/resolve
```
**Auth:** Any authenticated user.

Sets `resolved_at` to now. Alert is no longer returned in `status=firing` queries.

---

### Clear resolved alerts
```
DELETE /alerts/resolved
```
**Auth:** Admin only.

Permanently deletes all alerts that have been resolved.

---

### Clear all alerts
```
DELETE /alerts/all
```
**Auth:** Admin only.

Permanently deletes every alert record.

---

### Run idle VM check
```
POST /alerts/check
```
**Auth:** Admin only.

Queries Prometheus for each VM. If a VM has CPU < 5%, RAM < 20%, and network < 10 KB/s it is considered idle. An `idle_vm` warning alert is created (deduplicated — no duplicate within 2 hours) and an email is sent to the VM's owner.

**Response:**
```json
{ "fired": 1, "vms": ["10.150.40.10:9100"] }
```

---

### Send test email
```
POST /alerts/test-email
```
**Auth:** Admin only.

Sends a test email to verify SMTP configuration is working.

## Cost calculation formula

For each hourly billing period:

```
cpu_cost     = (cpu_pct / 100) × cpu_cores × cpu_rate_per_core_hour
ram_cost     = (ram_pct / 100) × ram_gb    × ram_rate_per_gb_hour
network_cost = (net_bytes / 1 GB)          × network_rate_per_gb
total_cost   = cpu_cost + ram_cost + network_cost
```

Metrics are sourced from Prometheus (Node Exporter). Default Standard tariff rates:

| Resource | Rate |
|---|---|
| CPU | $0.048 / core / hour |
| RAM | $0.006 / GB / hour |
| Network | $0.010 / GB |

## Quick-start example (curl)

```bash
# 1. Bootstrap admin (first time only)
curl -X POST http://localhost:8000/auth/setup-admin

# 2. Login
TOKEN=$(curl -s -X POST http://localhost:8000/auth/login \
  -d "username=admin&password=cloudcost2024" | jq -r '.access_token')

# 3. Seed default tariffs
curl -s -X POST http://localhost:8000/vms/seed \
  -H "Authorization: Bearer $TOKEN"

# 4. List VMs (auto-discovers from Prometheus)
curl -s http://localhost:8000/vms/ \
  -H "Authorization: Bearer $TOKEN" | jq .

# 5. Run billing
curl -s -X POST http://localhost:8000/billing/run \
  -H "Authorization: Bearer $TOKEN" | jq .

# 6. Get forecast for a VM
curl -s "http://localhost:8000/forecast/10.150.40.10%3A9100" \
  -H "Authorization: Bearer $TOKEN" | jq .
```
